# Data Structures & Algorithms (DSA) Solutions 🚀

This repository contains my personal collection of Data Structures and Algorithms solutions, revisions, and practice codes in C++.

## 📂 Repository Structure

The problems are categorized by core DSA topics and structured revision days:

| Directory | Topic / Description |
| :--- | :--- |
| `array/` | Array fundamentals, two pointers, prefix sums, element manipulation |
| `binary search/` | Binary search variants, pivot elements, square root, dynamic arrays |
| `Binary Tree/` | Tree traversals, depth/height, leaf counts, views |
| `Char_Array_String/` | String processing, reversals, palindrome checks, pattern matching |
| `2 D Array/` | Matrix operations, 2D grid searches, spiral traversals |
| `Linked Lists/` | Singly, Doubly, and Circular Linked Lists, reversing, node insertion/deletion |
| `Stack/` | Stack implementation, parentheses validation, next smaller element, celebrity problem |
| `Queue/` | Queue via array, circular queue, reverse first K elements, circular tour |
| `recursion/` | Basic recursion, subsets, permutations, phone keypad, merge sort, quick sort |
| `Sorting/` | Bubble sort, Selection sort, Insertion sort, Merge sort |
| `sliding window/` | Maximum average subarray, sliding window problems |
| `OOPs/` | Object-oriented concepts in C++, inheritance, polymorphism, encapsulation |
| `Pointers/` | Double pointers, array pointers, reference variables, memory management |
| `vector/` | C++ STL vector usage and dynamics |
| `Revision/` | Structured day-by-day revision modules (Day 01 to Day 14) |
| `revise/` | Fast recursion and sorting revision sets |
